# 项目简报：Figma 到 H5 个人资料卡课程案例

版本: 1.0

创建日期: 2025-10-12

作者: Analyst Mary

### 1. **行政摘要 (Executive Summary)**

本项目旨在创建一个教学案例，核心是指导学生完成一个“用户个人资料卡”组件。学生将首先在 Figma 中使用专业的设计系统方法（如样式和组件）进行设计，然后使用 HTML5 和 CSS3 在代码中精确复现该设计。此举旨在帮助初学者直观地建立从视觉设计到前端代码的映射关系，奠定“设计即代码”的 foundational a认知。

### 2. **问题陈述 (Problem Statement)**

目前，许多初级前端开发者和 UI 设计师在学习过程中存在知识鸿沟：

- **设计与代码脱节**: 他们可能了解 Figma 的基本操作，也学习了 HTML/CSS 语法，但很难将两者有机地联系起来。他们不清楚 Figma 中的“填充”、“描边”、“阴影”等属性如何精确地转化为 CSS 代码。
    
- **缺乏系统思维**: 许多教程只教授孤立的技能，而未引入设计系统和组件化开发的思想，导致学生在未来的工作中难以编写可维护、可扩展的代码。
    

### 3. **提议的解决方案 (Proposed Solution)**

我们将通过一个端到端的实践案例——“打造你的专属个人资料卡”，来解决上述问题。整个流程分为两个核心部分：

1. **Figma 设计阶段**: 引导学生不仅是“画”出卡片，更是“构建”一个微型设计系统，包括定义颜色、文本、效果样式，并使用 Auto Layout 和组件变体（Variants）来创建灵活、可复用的设计。
    
2. **H5 实现阶段**: 指导学生搭建语义化的 HTML 结构，并编写遵循 BEM 规范的 CSS 代码，将 Figma 中的每一个设计决策“翻译”为对应的 CSS 规则。
    

### 4. **目标用户 (Target Users)**

- **初级前端开发者**: 希望理解如何将设计稿转化为高质量代码的学生。
    
- **UI/UX 设计初学者**: 希望了解其设计如何被实现，以便更好地与开发人员协作的设计师。
    
- **对全栈开发感兴趣的学生**: 需要全面了解产品从设计到实现全过程的学习者。
    

### 5. **目标与成功指标 (Goals & Success Metrics)**

- **目标 1**: 学生能够清晰地阐述 Figma 核心样式属性与 CSS 属性之间的对应关系。
    
    - **成功指标**: 课程结束后，90% 的学生能够独立完成一份“Figma-CSS 属性对应表”。
        
- **目标 2**: 学生能够使用 HTML/CSS 像素级还原一个给定的 Figma 设计稿。
    
    - **成功指标**: 学生提交的最终代码产出，在浏览器中的视觉效果与 Figma 设计稿的差异度低于 5%。
        
- **目标 3**: 学生初步掌握组件化设计和 BEM 命名规范。
    
    - **成功指标**: 学生的 CSS 代码遵循 BEM 命名约定，且 HTML 结构语义清晰。
        

### 6. **项目范围 (MVP Scope)**

- **核心功能 (In-Scope)**:
    
    - 一个包含头像、姓名、简介的个人资料卡基础布局。
        
    - 使用 Figma Styles 定义颜色、文本样式和阴影。
        
    - 使用 Auto Layout 保证布局灵活性。
        
    - 将卡片创建为 Figma Component，并包含 `default` 和 `hover` 两种状态的 Variants。
        
    - 使用 HTML/CSS 实现卡片的静态布局和样式。
        
    - 实现 `hover` 状态下的微交互动画（如轻微放大和阴影加深）。
        
- **范围之外 (Out-of-Scope)**:
    
    - 复杂的响应式设计（本次重点是 1:1 还原）。
        
    - JavaScript 交互。
        
    - 与后端 API 的数据交互。
