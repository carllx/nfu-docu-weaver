# 头像图片说明

## 方法1：从 Figma 手动导出
1. 在 Figma 中选择 "Avatar" 元素
2. 右键 → Export → PNG (2x)
3. 保存为 `avatar.png` 到此文件夹

## 方法2：使用占位符图片
可以使用任何 80x80px 的圆形图片，或者方形图片（CSS 会自动处理圆形裁剪）

## 方法3：在线占位符
访问 https://via.placeholder.com/160x160/D3D3D3/D3D3D3.png
下载并重命名为 `avatar.png`

## 临时方案
如果暂时没有图片，HTML 中的 `alt` 属性和 CSS 中的 `background` 颜色会提供视觉占位。
