### 练习 1：改变主题色（3 分钟）

**基础版**：
```css
/* 在 style-basic.css 中找到并修改 */
.card {
  background: #FF6B6B;  /* 改成红色 */
}
```

**进阶版**：
```css
/* 在 style.css 中找到并修改 */
:root {
  --color-primary-brand: #FF6B6B;  /* 改这一处即可 */
}
```
