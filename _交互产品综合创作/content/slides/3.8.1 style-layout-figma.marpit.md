## ⏸️ 需要手动操作


<!--  _class: lead-->

---


### 📋 分步检查清单

#### A. 创建样式库

**1. 颜色样式:**
- [ ] 选择卡片背景 → 点击填充颜色 → 样式图标（4个点）→ "+" → 创建样式
  - 名称: `Color / Primary-Brand`
  - 值: `#8A2BE2`

---


- [ ] 选择头像 → 点击填充 → 创建样式
  - 名称: `Color / Avatar-Placeholder`
  - 值: `#D3D3D3`

---


- [ ] 创建额外的颜色样式（供参考）:
  - 名称: `Color / Primary-Text`
  - 值: `#FFFFFF`

---


**2. 文本样式:**

- [ ] 选择"名称"文本 → 右侧面板 → 类型详情 → 样式图标 → "+" → 创建样式
  - 名称: `Text / Heading-Name`
  - 设置: 24px, 粗体 (700),  **居中对齐**, 白色

---


- [ ] 选择"简介"文本 → 创建样式
  - 名称: `Text / Body-Bio`
  - 设置: 16px, 常规 (400), **居中对齐**, 白色 80% 透明度
  - White 80% 应该在 Fill 定义

![bg fit left:50% vertical](https://i.imgur.com/JIAW1Mj.webp)

---


**3. Effects 效果样式（阴影）:**
- [ ] 选择"Profile Card"框架 → 效果部分（右侧面板）→ "+" → 投影
  - X: `0`, Y: `4`, 模糊: `8`, 扩散: `0`
  - 颜色: `rgba(0, 0, 0, 0.1)`
  - 点击样式图标 → 创建样式
  - 名称: `Effect / Card-Shadow-Default`


---
Profile Card 的效果样式（阴影）不能直接创建,
命名为 Name: `Effect / Card-Shadow-Default` 或 `Effect / Card-Shadow-Hover` 的样式
这样在页面上添加样式后点击 Profile Card 分别应用更方便
![bg fit left:50% vertical](https://i.imgur.com/l3tn7KJ.webp)

![bg fit left:50% vertical](https://i.imgur.com/nJAFUtj.webp)


---


- [ ] 创建第二个阴影样式（用于悬停状态）:
  - 在样式面板中 → "+" → 效果样式
  - 名称: `Effect / Card-Shadow-Hover`
  - 投影: X: `0`, Y: `8`, 模糊: `16`, 扩散: `0`, 颜色: `rgba(0, 0, 0, 0.2)`

---

#### B. 设置文本对齐

- [ ] 选择"名称"文本 → 右侧面板 → 文本部分 → 对齐: **居中**（中间按钮）
- [ ] 选择"简介"文本 → 右侧面板 → 文本部分 → 对齐: **居中**（中间按钮）

---

#### C. 转换为带变体的组件

**1. 创建组件:**
- [ ] 选择整个"Profile Card"框架
- [ ] 右键点击 → **"创建组件"**（或 `Ctrl+Alt+K` / `Cmd+Option+K`）
- [ ] 确认名称为"Profile Card"

![bg fit left:50% vertical](https://i.imgur.com/b0qT8eW.webp)


![bg fit left:50% vertical](https://i.imgur.com/lZWKZna.webp)


---

**2. 添加变体:**
- [ ] 选择组件 → 右键点击 → **"添加变体"**
- [ ] 在右侧面板 → 属性部分 → 点击"+" → 添加属性
  - 属性名称: `State`
  - 类型: 变体
  - 值: `Default`, `Hover`

---

**3. 配置悬停变体:**
- [ ] 在组件集中，点击 `State=Hover` 变体
- [ ] 效果部分 → 移除 `Card-Shadow-Default` → 应用 `Effect / Card-Shadow-Hover`
- [ ] （可选）您可以稍微调整其他属性以显示悬停状态

---

#### D. 将样式应用到元素

- [ ] 选择卡片背景 → 填充 → 选择 `Color / Primary-Brand` 样式
- [ ] 选择"名称"文本 → 应用 `Text / Heading-Name` 样式
- [ ] 选择"简介"文本 → 应用 `Text / Body-Bio` 样式
- [ ] 选择头像 → 填充 → 选择 `Color / Avatar-Placeholder` 样式
- [ ] 选择卡片 → 效果 → 应用 `Effect / Card-Shadow-Default` 样式
