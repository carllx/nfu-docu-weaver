# 项目简报: TouchDesigner 头部追踪 VR

## Executive Summary

本项目旨在创作一件当代数字艺术作品，其核心是一个可交互的虚拟“满洲窗”。此“窗户”融合了满族、岭南及西方文化元素，通过数字手段实现复现。作品将利用 TouchDesigner 平台，并结合其内置的 Face Track（面部追踪）节点或 Kinect V2 等体感设备，实现精准的头部追踪。

当前，标准的电脑屏幕无论内容多具三维感，其显示本身仍是二维平面，无法根据观看者的视角变化而改变。本项目的解决方案，正是将屏幕转化为这扇充满文化意蕴的“满洲窗”，让观众得以“窥见”一个过去的岭南室内空间，体验一段尘封的记忆或故事。其核心价值主张在于，不仅仅是创建一个技术上的桌面虚拟现实（Desktop Virtual Reality）效果，更是将传统的平面显示器，升华为一个连接现在与过去、融合多元文化的动态叙事门户，为观众带来兼具沉浸感与情感共鸣的艺术体验。

## Problem Statement

标准的数字屏幕提供的是一个固定的、二维的观看体验。这种呈现方式不仅与人类记忆的本质存在根本性的冲突，也无法体现记忆与历史的深刻区别。

1. **理论支撑：将“历史”转化为“活的记忆”**
    
    - 根据**莫里斯·哈布瓦赫斯**的理论，**“历史”**与**“记忆”**是截然不同的：历史是客观、普适、疏远的叙述，始于记忆的中断；而集体记忆则是主观的、属于特定群体的、并且总是在当下被社会根据其参照框架进行**重构**的鲜活体验。
        
    - 哈布瓦赫斯进一步指出，记忆需要具体的“场所”并倾向于**空间化**，形成承载情感与思想的**“记忆形象”**。一个褪色的、平面的图像，仅仅是“历史”的档案，而非“活的记忆”。
        
    - 因此，本作品要解决的核心问题是：如何设计一种交互体验，让观众不仅仅是“观看”一段关于岭南的“历史”，而是能作为当代社会的一员，亲身“参与”到将这段历史**重构为集体记忆**的过程中？
        
2. 艺术挑战：从被动观察到主动重构
    
    将一段丰富的“岭南记忆”压缩在一个静态的二维平面上，观众只能成为历史的被动观察者。为了让观众成为记忆的主动参与者和重构者，艺术作品必须提供一个能够体现“社会制约性”和“空间化”的交互框架。
    

## Proposed Solution

本项目的解决方案是一个**由视觉驱动的两阶段式交互系统**，它将哈布瓦赫斯与阿斯曼的记忆理论转化为具体的交互行为，引导观众完成从“历史”到“活的记忆”的转变。

1. **核心技术**：我们将采用 TouchDesigner 作为主要的开发平台。通过其内置的 **Face Track CHOP** 或外接的 **Kinect V2** 传感器，系统将实时捕捉观众头部在三维空间中的位置 `(x, y, z)` 和旋转姿态。
    
2. 交互模型：远观重构历史，近窥沉浸记忆
    
    交互体验将根据观众与屏幕的距离分为两个明确的阶段，直接映射哈布瓦赫斯的理论框架：
    
    - **第一阶段：远观 - 将历史重构为记忆 (Distance > Threshold)**
        
        - **理论映射**：此阶段直接呼应了哈布瓦赫斯关于**“记忆的社会制约性”**和**“重构性”**的论点。初始褪色或不完整的窗户代表着**“历史”**——一个客观但疏远的文化档案。观众（作为当代社会群体的代表）通过“凝视赋色”，正是将当下的社会框架投射到历史之上，主动进行“重构”，从而将冰冷的历史转化为鲜活的集体记忆的一部分。
            
        - **交互：“凝视选择”与赋色**
            
            - 观众头部的**旋转姿态**被映射为虚拟指针，通过**停留（Dwell）**在特定窗格上进行“选择”。
                
            - 成功的选择会触发“赋色”效果，为这个历史框架注入色彩和生命力。这个过程本身构成了阿斯曼所说的**“文化记忆”的仪式化激活**。
                
    - **第二阶段：近窥 - 沉浸于活的记忆 (Distance <= Threshold)**
        
        - **理论映射**：此阶段体现了从“历史”到“活的记忆”的转变。当记忆的框架被重构（窗户被着色）后，观众便获得了“进入”这个主观、三维记忆空间的资格。这完美对应了哈布瓦赫斯所强调的，记忆是具体的、**空间化的**，并且充满了可感知的**“记忆形象”**（如西关小姐的侧影），是一种与群体身份紧密相连的体验。
            
        - **交互：三维空间探索**
            
            - 观众头部的**位置** `(x, y, z)` 用于实时计算**非对称视锥**，实现逼真的三维视差效果。
                
            - 观众可以通过身体移动，自由探索窗内那个被“激活”的三维记忆空间，成为故事的亲历者。
                
            - 第一阶段被“赋色”的窗格，在此时将成为**观察记忆的滤镜**，为窗内的景象染上不同的色彩和情绪。
                
3. **叙事内容**：窗内将构建一个精细的 3D 场景，再现一个特定历史时期的岭南室内空间。其中可能包含“西关小姐的侧影”、“算盘的影子”等具象化的**“记忆形象”**。此空间将承载一段精心设计的微型叙事或“记忆切片”，观众通过移动身体和“凝视”，可以在这个三维记忆中发现并“激活”故事的线索。
    
4. **视觉呈现与多层体验**：为了模拟真实的观看体验，视觉呈现将分为多个层次。屏幕的第一层将渲染**满洲窗的物理结构**，包括其木质框架、雕花和窗内窗体的颜色。其后的 3D 记忆场景将**透过一个虚拟的“玻璃层”**被观察。这一层将通过着色器（Shader）处理，模拟传统彩色玻璃的质感、颜色、光线折射以及可能存在的瑕疵。观众与屏幕的距离远近，将影响“玻璃”的清晰度和焦散效果，从而让“记忆”的影像呈现出一种既真实又略带疏离感的美学特征。
    
5. **独特性**：此方案确保了最终作品的独特性和概念的纯粹性。它不是一个可以被任何“窗户”所替代的通用设计，而是专为“岭南满洲窗”这一文化符号量身定制的数字艺术体验。技术（头部追踪）成为了连接观众与特定文化记忆（岭南故事）的**唯一桥梁**，通过观众的视觉探索，实现从“历史的褪色”到“记忆的显影”的转变。
   
   
   
   因为我还是觉得刚才的方案存在和理论的脱节，因为你这里有一个理论是关于集体记忆的，并且有涉及到存档以及重构。所以目前我这里调整了一下，核心调整逻辑可梳理为3点，清晰对应“集体记忆”理论中的存档与重构：

1. 基础记忆（存档）：未使用赋颜功能时，观众看到的窗格内空间模型为黑白效果，对应原始、统一的记忆存档状态。

2. 观众参与（重构）：观众对窗格进行赋颜操作后，窗格的玻璃颜色与光线会作为“着色源”。

3. 个性化呈现（记忆重构结果）：不同观众选择的颜色不同，最终着色到白色空间模型上的效果也不同，实现集体记忆下的个性化重构呈现。
