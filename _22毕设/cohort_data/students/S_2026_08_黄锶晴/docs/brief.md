# 项目简报: TouchDesigner 头部追踪 VR

## Executive Summary

本项目旨在创作一件当代数字艺术作品，其核心是一个可交互的虚拟“满洲窗”。此“窗户”融合了满族、岭南及西方文化元素，通过数字手段实现复现。作品将利用 TouchDesigner 平台，并结合其内置的 Face Track（面部追踪）节点或 Kinect V2 等体感设备，实现精准的头部追踪。

当前，标准的电脑屏幕无论内容多具三维感，其显示本身仍是二维平面，无法根据观看者的视角变化而改变。本项目的解决方案，正是将屏幕转化为这扇充满文化意蕴的“满洲窗”，让观众得以“窥见”一个过去的岭南室内空间，体验一段尘封的记忆或故事。其核心价值主张在于，不仅仅是创建一个技术上的桌面虚拟现实（Desktop Virtual Reality）效果，更是将传统的平面显示器，升华为一个连接现在与过去、融合多元文化的动态叙事门户，为观众带来兼具沉浸感与情感共鸣的艺术体验。

## Problem Statement

标准的数字屏幕提供的是一个固定的、二维的观看体验。这种呈现方式与人类记忆的本质存在根本性的冲突。

1. **理论支撑：记忆的空间性与社会性框架**
    
    - 根据法国社会学家**莫里斯·哈布瓦赫斯**的理论，记忆并非孤立存在于个体大脑中，它需要一个**社会框架**来构建和维持。记忆需要具体的“场所”并倾向于**空间化**。本项目中的“满洲窗”正是这样一个承载岭南集体记忆的文化与空间框架。因此，要真实地体验这段记忆，就必须在一个三维空间中对其进行“重构”，而非平面展示。
        
    - **扬·阿斯曼**的“文化记忆”理论进一步指出，这种记忆是关于**“意义的传承”**，它通过仪式化的方式被激活。我们的交互过程——“赋色”与“窥探”——正是这样一种仪式，它将一段“被记忆的历史”转化为观众可以亲身参与和感知的神话。
        
2. 艺术挑战：打破二维束缚
    
    将一段丰富的“岭南记忆”压缩在一个静态的二维平面上，会剥离其深度和层次感，迫使观众成为被动的观察者。为了真实地传达记忆的空间感和沉浸感，艺术作品必须超越平面的限制。因此，本项目要解决的核心问题是：如何利用头部追踪技术，将“满洲窗”构建成一个符合记忆理论的、可交互的三维空间框架，让观众通过身体的移动和凝视，参与到文化记忆的“赋色”与“显影”过程中。
    

## Proposed Solution

本项目的解决方案是一个**由视觉驱动的两阶段式交互系统**，它将头部追踪技术与“记忆赋色”概念深度融合，旨在实现“意义的传承”。

1. **核心技术**：我们将采用 TouchDesigner 作为主要的开发平台。通过其内置的 **Face Track CHOP** 或外接的 **Kinect V2** 传感器，系统将实时捕捉观众头部在三维空间中的位置 `(x, y, z)` 和旋转姿态。
    
2. 交互模型：远观赋色，近窥记忆
    
    交互体验将根据观众与屏幕的距离分为两个明确的阶段：
    
    - **第一阶段：远观 - 记忆的赋色 (Distance > Threshold)**
        
        - **状态**：当观众距离屏幕较远时，屏幕主要呈现满洲窗的**表象**——一个精美的、但色彩可能是褪去或不完整的木质窗格结构。窗内的三维记忆空间是模糊、抽象或不可见的。
            
        - **交互：“凝视选择”机制**
            
            - **指针控制**：观众头部的**旋转姿态**将被映射为一个虚拟的指针或焦点。如同用视线操控鼠标，观众可以通过转动头部，将这个焦点移动到被木质结构隔开的不同窗格上。
                
            - **选择与赋色**：当焦点在某个窗格上**停留（Dwell）**超过预设时间（例如1.5秒），该窗格将被“选中”。系统会触发“赋色”效果，该窗格的玻璃颜色会逐渐恢复或被“点亮”，并可能伴随有相应的音效或视觉反馈。
                
        - **目的**：此阶段的目的是让观众参与到**“重构记忆框架”**的仪式中，通过自己的凝视，为承载记忆的媒介（窗户）恢复色彩。
            
    - **第二阶段：近窥 - 记忆的显影 (Distance <= Threshold)**
        
        - **状态**：当观众**靠近**屏幕，越过一个设定的距离阈值时，交互模式发生转变。满洲窗的玻璃变得通透，窗内那个尘封的**三维岭南记忆空间清晰地“显影”出来**。
            
        - **交互：三维空间探索**
            
            - **视差体验**：此时，观众头部的**位置** `(x, y, z)` 将用于实时计算一个**非对称视锥（Asymmetric Frustum Projection）**。观众可以通过移动、蹲下、倾斜身体，从不同角度窥探窗内的房间，看到物体的遮挡关系和空间深度，仿佛在通过一个真实的窗户观察。
                
            - **色彩滤镜**：第一阶段被“赋色”的窗格，在此时将成为**观察记忆的滤镜**，为窗内的景象染上不同的色彩和情绪。
                
        - **目的**：此阶段让观众 **“进入”** 并探索已重构的记忆空间，成为故事的亲历者。
            
3. **叙事内容**：窗内将构建一个精细的 3D 场景，再现一个特定历史时期的岭南室内空间。其中可能包含“西关小姐的侧影”、“算盘的影子”等具象化的记忆形象。此空间将承载一段精心设计的微型叙事或“记忆切片”，观众通过移动身体和“凝视”，可以在这个三维记忆中发现并“激活”故事的线索。
    
4. **视觉呈现与多层体验**：为了模拟真实的观看体验，视觉呈现将分为多个层次。屏幕的第一层将渲染**满洲窗的物理结构**，包括其木质框架、雕花和窗内窗体的颜色。其后的 3D 记忆场景将**透过一个虚拟的“玻璃层”** 被观察。这一层将通过着色器（Shader）处理，模拟传统彩色玻璃的质感、颜色、光线折射以及可能存在的瑕疵。观众与屏幕的距离远近，将影响“玻璃”的清晰度和焦散效果，从而让“记忆”的影像呈现出一种既真实又略带疏离感的美学特征。
    
5. **独特性**：此方案确保了最终作品的独特性和概念的纯粹性。它不是一个可以被任何“窗户”所替代的通用设计，而是专为“岭南满洲窗”这一文化符号量身定制的数字艺术体验。技术（头部追踪）成为了连接观众与特定文化记忆（岭南故事）的**唯一桥梁**，通过观众的视觉探索，实现从“历史的褪色”到“记忆的显影”的转变。
