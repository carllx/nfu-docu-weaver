# 页面二：《造物与创格》课程应用原型

> ⚠️ **以下所有内容均为 Agent 结合知识库生成的【课程推论】，并非通用理论，亦非最终教学决定。**

## 一、该概念可能产生的教学问题

- **认知撕裂**：如果开篇仅讲授 Flusser（形式先验、设计即欺骗），学生在后期面对强调“具身认知”的创作（如用双手探索粘土、随机生成算法）时，会产生理论与实践的脱节感。
- **掌控欲困境**：受传统“设计=规划”的影响，学生极易在一开始就画出死板的草图，随后强行用软件或材料复刻。当材料属性（如重力、软件bug）反抗预设形式时，他们容易感到挫败，而非将“生成过程”视为创作的一部分。

## 二、可采用的课堂活动建议

1. **“蒙眼识物”或“材料对话”**（呼应 Kirsh 的 Doing 优于 Seeing）：
   - 要求学生在没有任何设计图的情况下，随机分配一种材料（例如纸、废旧五金、或者开源代码片段）。
   - 让学生通过身体干预（如揉捏、破坏、盲写）去感受媒介自身的特性，从中“生成”一个小物件，体验非先验的形式产生过程。
2. **“非人类参与造物”**（呼应 Tim Knowles）：
   - 布置一个小练习：设计一个结构，让自然力（风、水流）或机器随机性来完成最终的画面/形态，体验人类退居次位的造物过程。

## 三、可能的艺术家案例

- **Tim Knowles (树木素描)**：用于展示如何彻底放弃预设形式，让生成过程主导。
- **Rebecca Horn (Unicorn 1970等身体延伸物)**：用于探讨身体物理限制如何通过穿戴物重塑空间形态（见知识库 `Rebecca Horn.md` 中关于身体与空间关系的论述）。
- **Quayola (Pleasant Places 系列)**：用于讨论数字工具如何重新审视自然形式（见知识库 `Quayola - PP_F_024_2 (2021) - 自然与技术融合.md` 中印象派理念与算法生成的结合）。

## 四、对不同学生基础的风险

- **对于技术流学生（如熟练掌握 3D/编程）**：他们习惯于 Flusser 式的“自上而下赋形”，在面对“材料生成”时可能会认为这缺乏“技术含量”和“控制力”。
- **对于直觉流学生（如纯艺背景）**：可能会抗拒 Flusser 的“技术欺骗论”，觉得其对工具的定义过于机械化，需要用具身认知理论来平衡他们的抵触。

## 五、Agent 建议

建议在《造物与创格》的“造物”核心模块中，安排一次**“理论对撞 (Theoretical Tension)”**讨论：
前半节课通过 Flusser 确立“设计就是把理念强加于物质”的传统基调；后半节课立即抛出 Tim Knowles 的案例和具身认知，要求学生反思在即将进行的创作中，到底是谁在决定作品的“形式”。
