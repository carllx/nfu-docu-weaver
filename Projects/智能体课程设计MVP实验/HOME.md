# 智能体课程设计MVP实验

## 1. 项目焦点 (Project Focus)
- **核心目标**：验证基于 NotebookLM 作为证据底座，通过多智能体协作（教材证据代理+课程主控）生成课程大纲的可行性。
- **当前状态**：最小可行性实验 (MVP) 阶段，避免过度工程化（即不引入复杂的 JSON/YAML 校验和 Python 运行时引擎）。
- **关联方法**：[[智能体课程设计法]]

## 2. 初步实验观察 (Preliminary Observations)
在一次课程大纲生成实验中，本流程成功产生了一个包含若干模块的初稿。
本次实验初步显示：
1. **降低无依据陈述、错误归因和错误综合风险**：限定来源与引用要求有助于降低无依据陈述和错误归因风险，但不能完全消除理解与综合错误。
2. **人类的不可替代性**：Agent 能协助整理教材贡献和潜在冲突，教学可行性仍必须由人类讲师裁决。
3. **精简架构易于执行**：与此前更复杂的运行时设想相比，精简流程在本次实验中更容易执行。

这些结论仍需通过更多真实课程任务验证，暂不视为普遍规律。
