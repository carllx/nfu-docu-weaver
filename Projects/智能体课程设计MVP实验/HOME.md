# 智能体课程设计MVP实验

## 1. 项目焦点 (Project Focus)
- **核心目标**：验证基于 NotebookLM 作为证据底座，通过多智能体协作（教材代表+课程主控）生成课程大纲的可行性。
- **当前状态**：最小可行性实验 (MVP) 阶段，避免过度工程化（即不引入复杂的 JSON/YAML 校验和 Python 运行时引擎）。
- **关联方法**：[[智能体课程设计法]]

## 2. 实验结论 (Findings)
我曾经在此框架下实践过，并**成功生成了一个包含 4~6 个模块的课程大纲**。
实验证明了以下几点核心判断：
1. **防止幻觉**：NotebookLM 能有效限定 Agent 的知识库，强制要求证据，避免模型凭空捏造不存在的理论。
2. **人类的不可替代性**：Agent 可以提供高质量的素材组合和争议点，但最终“怎么教”、“能不能教”必须由人类讲师基于真实教学场景来裁定。
3. **架构收敛**：过度复杂的流程反而难以执行，聚焦于“单书提案 -> 互评质疑 -> 主控合成大纲 -> 人类验收”这一精简流程，效率和效果最佳。
