

### 核心概念：一句话理解透明材质

在 Arnold 中制作任何透明物体（玻璃、塑料、水），你只需要记住一个核心操作：  
**关掉物体表面的“油漆”（Base Color），让光线可以“穿透”它（Transmission）。**

---

### 第 1 步：制作微蓝色塑料桶材质

这个材质的关键是：**半透明、表面有点模糊（磨砂感），并且整体带一点蓝色。**

1. **创建新材质**
    
    - 选中你的塑料桶模型。
        
    - 右键长按，选择 指定新材质 (Assign New Material)。
        
    - 在弹出的窗口中，选择 aiStandardSurface。给它命名，比如 mat_plastic_bucket。
        
2. **设置材质属性（在属性编辑器里）**
    
    - **Base (基础)**
        
        - 将 Weight (权重) **降到 0**。
            
            - **为什么？** 我们不希望桶的表面有任何颜色，颜色应该来自于光线穿透它之后产生的。
                
    - **Specular (高光)**
        
        - 保持 Weight (权重) 为 1。
            
        - 将 Roughness (粗糙度) **稍微提高一点**，比如 0.2 或 0.3。
            
            - **为什么？** 这是实现“低多边形风格”的关键。完美的镜面反射太真实了，增加一点粗糙度会让高光变得模糊，产生磨砂或哑光的质感，更符合 stylized 风格。
                
    - **Transmission (透射/透明)**
        
        - 将 Weight (权重) **设置为 1**。
            
            - **为什么？** 这就是开启“透明模式”的开关，让光线可以 100% 穿过。
                
        - 将 Color (颜色) **设置为淡淡的蓝色**。
            
            - **为什么？** 这就是决定你透明塑料颜色的地方。颜色越深，塑料看起来越厚重。
                
    - **Geometry (几何体)**
        
        - 勾选 Thin Walled (薄壁)。
            
            - **为什么？** 饮水机桶壁很薄，这个选项专门用来模拟这种单层曲面，效果更准确，渲染也更快。
                


---

### 第 2 步：制作内部的水材质

水的材质更纯粹，核心是：**完全透明、有水的正确折射效果。**

1. **创建新材质**
    
    - 选中饮水机内部的水模型。
        
    - 同样，为其指定一个新的 aiStandardSurface 材质，命名为 mat_water。
        
2. **设置材质属性**
    
    - **Base (基础)**
        
        - 将 Weight (权重) **降到 0**。 （和塑料桶一样，水表面没有颜色）
            
    - **Specular (高光)**
        
        - 将 IOR (折射率) **精确设置为 1.33**。
            
            - **为什么？** 这是真实水的物理属性。即使是低多边形风格，使用正确的折射率也能让光线穿过水时的弯曲效果看起来“像水”，这是最重要的物理特征。
                
        - Roughness (粗糙度) 保持很低的值，比如 0 或 0.05，让水面看起来清澈。
            
    - **Transmission (透射/透明)**
        
        - 将 Weight (权重) **设置为 1**。 （让水完全透明）
            
        - Color (颜色) 保持**白色**，代表这是清澈纯净的水。如果你想要带点颜色的水，可以在这里调整。
            

---

### 第 3 步：最关键的一步！让模型真正变透明

即使材质设置好了，你还必须告诉模型本身：“你是一个透明物体！” 否则渲染出来可能还是黑色的。

1. **选中塑料桶和水两个模型**。
    
2. 按下 Ctrl + A 打开属性编辑器，切换到 **形状节点 (Shape Node)** 标签页（通常是 pCylinderShape1 或类似的名字）。
    
3. 找到 Arnold 卷展栏。
    
4. **取消勾选 Opaque (不透明) 选项**。
    

**这一步绝对不能忘！** 它相当于为光线穿透模型开了“绿灯”。

### 重点总结 (初学者备忘录)

|   |   |   |   |   |
|---|---|---|---|---|
|材质|核心目标|Base Weight|Transmission Weight|关键参数调整|
|**塑料桶**|磨砂质感，带微蓝色|**0**|**1**|Specular Roughness 提高到 0.2 左右，Transmission Color 设为淡蓝色，勾选 Thin Walled。|
|**水**|清澈透明，物理准确|**0**|**1**|Specular IOR 设置为 **1.33**。|

最后，记得一定要在模型的 **形状节点 (Shape Node)** 中**取消勾选 Opaque**。

按照这个流程，你就能用最简单、最核心的参数，快速创建出符合低多边形风格的饮水机材质。
