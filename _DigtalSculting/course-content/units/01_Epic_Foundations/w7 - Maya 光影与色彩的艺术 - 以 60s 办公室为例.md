

**课程主题：** 以家居办公室为例，掌握基于物理与感知的专业光影设定与色彩搭配法则
### 一、 课程目标 (已升级)

完成本节课程后，学生将能够：

1. **建立物理渲染世界观：** 理解PBR流程的核心是“动机化光源”与全局光照，而非抽象的灯光模板。
    
2. **掌握功能性布光：** 将三点布光的“Key /Fill/ Rim”理解为场景中的“功能角色”，并用符合物理和叙事逻辑的“动机化光源”去实现它们。
    
3. **应用感知权重配色法：** 将60/30/10法则从简单的“面积比”升级为综合考量“面积、明度、饱和度”的“视觉份额”或“感知权重”模型。
    
4. **建立科学的创作管线：** 掌握“先定物理基线 -> 再塑光影结构 -> 后配感知色彩”的创作流程，并理解其对于项目管理和跨平台交付的巨大优势。
    
5. **实现可预测的云端展示：** 学会将Maya场景正确导出并上传至Sketchfab，通过色彩管理与参数校准，确保最终效果与创作意图一致。
    

### 二、 课前回顾与衔接

- **回顾上节课：** PBR材质基础——能量守恒（Energy Conservation）是我们讨论一切的基础。我们已了解材质如何响应光线。
    
- **本节课的衔接：** 上节课解决了“物体是什么”，这节课将解决“光从哪里来”以及“色彩如何被感知”。我们将把独立的PBR材质，置于一个统一的物理光照环境中，并用符合认知科学的色彩法则来组织它们。
    

### 三、 课程大纲 (已重构)

#### **第一部分：光线 —— 物理为底，感知为纲 (理论 + Maya 演示)**

1. **观念重塑：从“三点布光”到“动机化布光”**
    
    - **批判性分析：** 为什么不能将影棚的三点布光法直接套用到PBR室内场景？
        
        - **核心区别：** 三点布光是**为控制而生**的抽象范式；PBR场景是**模拟物理现实**的系统，强调光源的“动机”（Motivated Light Source）与全局光照（Global Illumination）。
            
    - **新的工作流：** 我们的目标不是摆放三个灯，而是回答三个问题：
        
        1. **场景的主要光源是什么？(Key light角色)** -> 来自窗户的日光？天花板的主灯？
            
        2. **环境光和反弹光如何？(Fill light角色)** -> 墙壁/地面的颜色和材质是什么？它们如何将Key light反弹到暗部？
            
        3. **有没有次要光源或强反射能勾勒轮廓？(Rim light角色)** -> 物体背后的台灯？窗外的霓虹灯？金属边缘的高光？
            
2. **物理基线的建立：设定场景的“世界规则”**
    
    - **引入HDRI环境光：** 作为基础环境光（天光、环境反射），为场景提供一个统一的“Fill light底色”和真实的反射源。
        
    - **设定曝光与色温 (EV & Kelvin)：**
        
        - **曝光 (Exposure):** 统一场景的曝光基准，所有灯光在此基础上调节。Arnold灯光中的Exposure参数以档位(f-stops)计算，更符合摄影逻辑。
            
        - **色温 (Color Temperature):** 为动机化光源赋予物理属性。例如：窗光设置为6500K（冷），室内的钨丝灯设置为3200K（暖）。建立场景的冷暖对比基调。
            
    - **规范材质反照率 (Albedo)：** PBR的核心原则——能量守恒。强调非金属物体的固有色（Base Color）明度应被严格限制在 `0.02 - 0.8` 之间，避免物理不正确的纯黑/纯白。
        
3. **感知的目标：格式塔理论中的“图地关系”**
    
    - **核心理念：** 布光的首要目标是建立清晰的“图地关系”（Figure-Ground Relationship），即让主体（图）从背景（地）中明确地分离出来。
        
    - **布光即设计：**
        
        - **Key light**塑造“图”的体积。
            
        - **Fill light**（主要由GI和HDRI提供）调节“图”与“地”的整体对比与和谐度。
            
        - **Rim light**是最终执行“分离”的锐利工具，确保“图”的边缘清晰可辨。
            
4. **【Maya 演示】构建一个物理可信的场景**
    
    - 步骤一 **(建立基线):** 场景赋予中性灰材质。载入一个HDRI，设定一个基础的渲染相机曝光值。
        
    - 步骤二 **(动机化Key light):** 在窗户位置创建一个`aiAreaLight`，开启色温模式设为6500K，调节Exposure，使其成为场景的主导光源。
        
    - 步骤三 **(观察Fill light):** 启用GI，观察墙壁和地面如何自然地反弹光线，形成“动机化Fill light”。解释反照率高的白色墙壁如何成为一个巨大的柔光板。
        
    - 步骤四 **(动机化Rim light):** 在主体道具（如椅子）背后放置一个小的`aiAreaLight`或`Mesh Light`模拟台灯，设为3200K暖色温，作为Rim light，演示其如何将椅子从背景中“剥离”出来。
        
    - **工具运用：** 打开Arnold RenderView的直方图或使用明度通道（Luminance AOV）来**量化**分析画面的明暗分布和图地分离程度。
        

#### **第二部分：色彩 —— 感知权重与和谐结构 (理论 + Maya 演示)**

1. **法则升级：从“面积比”到“感知权重”**
    
    - **批判性分析：** 为什么单纯的60/30/10面积比会失效？因为它忽略了明度和饱和度对视觉注意力的巨大影响。
        
    - **新的定义：** **视觉份额 ≈ 面积 × 明度 × 饱和度 × 位置显著度**。我们的目标是管理“视觉份额”，而非单纯的物理面积。
        
    - **60% 主色调 (基调与背景):** 通常是中明度、低饱和度的颜色，作为“地”，为场景提供稳定的情绪基底。
        
    - **30% 辅助色调 (主体与对比):** 与主色调在明度或色相上形成一定对比，用于主体物件，建立场景的“图”。
        
    - **10% 点缀色 (焦点与引导):** 通常是高明度、高饱和度或具有强烈对比的颜色，作为视觉焦点，引导观众视线。
        
2. **结构化配色：结合Munsell明度与Itten对比**
    
    - **Munsell明度层级：** 将色彩规划到不同的明度区间。例如：
        
        - **主色**控制在**中间调区域** (Munsell Value 5-6)。
            
        - **辅色**可以落在**暗部或亮部** (Value 3-4 或 7-8)，以建立对比。
            
        - **点缀色**则可以拥有最亮或最暗的明度，形成视觉焦点。
            
    - **Itten色彩对比：** 用专业的色彩理论指导“点缀色”的选择，而不是随机跳色。例如，使用**互补色对比**或**冷暖对比**来让点缀色更具结构意义。
        
3. **【Maya 演示】在无光环境中进行结构化上色**
    
    - _（操作同前，但在理论讲解上深化）_
        
    - 切换到无光照模式。
        
    - 步骤一 (主色): 选择一个中明度、低饱和的颜色作为主色调，赋予墙面。
        
    - 步骤二 (辅色): 选择一个与主色有明确明度差的颜色（如深木色），赋予家具。
        
    - 步骤三 (点缀色): 根据Itten的冷暖对比，如果场景是暖调，选择一个小面积的冷色（如蓝色靠垫）作为点缀。
        
    - **验证：** 完成后，打开灯光渲染，检查最终的“视觉份额”是否符合60/30/10的感知预期。
        

#### **第三部分：管线一致性 —— 从创作到交付 (理论 + 演示)**

1. **盲点警示：为什么你在Maya里看到的不等于客户在网页上看到的？**
    
    - **核心问题：** 颜色管理 (Color Management) 和 PBR 参数映射不一致。
        
    - **Arnold (ACEScg) vs. Sketchfab (sRGB/WebGL):** Arnold默认在更广的ACEScg色域工作，并使用电影化的色调映射（Tone Mapping）；而网页端普遍工作在sRGB色域。直接转换会导致色彩和亮度的“漂移”。
        
2. **建立可预测的导出管线**
    
    - **色彩空间校准：**
        
        - 工作流程：在Maya (ACEScg)中工作，但在导出贴图前，应将贴图文件（如BaseColor）**转换到sRGB色域**。
            
        - **最佳实践：** 在场景中放置一个标准的**灰球或ColorChecker色卡**。渲染一张图，导出模型到Sketchfab后，在Sketchfab的3D设置中对比色卡颜色，手动校准曝光、对比度等参数，以最大程度匹配Arnold的渲染结果。
            
    - **PBR参数打包：**
        
        - 确保导出时，金属度(Metalness)和粗糙度(Roughness)通道被正确打包到Sketchfab所期望的纹理格式中（例如，对于glTF格式，通常是打包在同一张贴图的不同通道，如G通道存Roughness，B通道存Metalness）。
            
3. **【演示】从Maya到Sketchfab的“无损”交付**
    
    - 演示如何将贴图批量转换为sRGB。
        
    - 演示如何使用glTF格式导出，并解释其PBR通道打包的优势。
        
    - 在Sketchfab中上传模型，并使用之前渲染的带色卡的图像作为参照，调整Sketchfab中的后处理设置（曝光、对比度、色调映射），直到色卡颜色匹配。
        

### 四、 课堂活动与学生实践

#### **从 Maya 到 Sketchfab (演示)**

1. **模型与材质准备：** 检查模型命名、清理历史记录、确保材质命名规范。
    
2. **导出与上传：**
    
    - 演示如何从 Maya 中导出为 Sketchfab 支持的格式（如 `.fbx` 或 `.gltf`）。
        
    - 登录 Sketchfab 网站，创建一个新模型并上传文件。
        
3. **Sketchfab 在线编辑器：**
    
    - 上传完成后，进入 3D Settings 界面。
        
    - **核心优势演示：** 由于我们前期材质管理做得好，现在可以轻松地在 Sketchfab 的材质编辑器中对主色、辅色进行微调，甚至替换贴图，实时预览效果，这对于向客户展示和快速迭代方案是无价的。
    
- **任务要求：** 学生需明确标注出场景中每个灯光的“动机”，并提交一份简短的色彩分析，说明其主/辅/点缀色是如何根据“感知权重”原则选择的。
    

### 五、 课程总结与课后作业

- **总结关键点 (已深化):**
    
    1. **动机优先：** 先思考光从哪来，再决定灯怎么打。
        
    2. **物理为基：** 色温、曝光、能量守恒是PBR的基础语法。
        
    3. **感知为王：** 布光是为了分离图地，配色是为了组织视觉权重。
        
    4. **管线意识：** 创作的终点是交付，必须保证跨平台的一致性。
        
- **课后作业 (已升级):**
    
     
        
    - 完成自己的办公室场景，并上传到Sketchfab。**额外要求：** 在作品描述中，用一句话解释你的Key light源、Fill light源和Rim light源分别是什么“动机化”来源，并简述你的60/30/10色彩层级是如何按“感知权重”构建的。
- **总结关键点：**
    
    1. 光是素描，色是情感。
        
    2. 三点布光法是基础和核心。
        
    3. 60/30/10 法则是安全且出效果的配色指南。
        
    4. 科学的流程和管理是高效产出的保障。
        
    5. Sketchfab 是展示和迭代作品的利器。
        
- **课后作业：**
    
    - 寻找 3 张你喜欢的室内设计、UI 设计或电影截图。
        
    - 分析并标注出它们的三点布光（如果明显）和 60/30/10 配色方案。
        
    - 完成自己的办公室场景的布光和上色，并上传到 Sketchfab，将链接提交至学习平台。
