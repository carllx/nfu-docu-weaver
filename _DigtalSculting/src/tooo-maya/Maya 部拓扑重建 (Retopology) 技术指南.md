# Maya 生物头部拓扑重建 (Retopology) 技术指南

本文档基于 FlippedNormals 的教学视频整理，旨在为学生提供 Maya 中进行生物头部拓扑重建（Retopology）的核心命令梳理、流程要点总结及中英文术语对照。

## 1. 核心命令与工具对照表 (Commands & Terminology)

在 Maya 中进行拓扑重建，主要依赖于 **Modeling Toolkit (建模工具包)** 中的工具。以下是视频中提到的关键命令及其作用。

|             |                             |                                  |                                                             |
| ----------- | --------------------------- | -------------------------------- | ----------------------------------------------------------- |
| **中文命令/术语** | **英文命令/术语**                 | **快捷键/操作方式**                     | **核心作用与使用场景**                                               |
| **激活表面**    | **Live Surface**            | 磁铁图标 (顶部工具栏)                     | **基础环境设置**。将高模设置为“吸附基准”，确保所有新创建的点和面都紧贴在高模表面上。这是拓扑的第一步。      |
| **四边形绘制**   | **Quad Draw**               | Modeling Toolkit 面板              | **核心工具**。全能型拓扑工具，用于绘制点、创建面、调整顶点。整个拓扑过程 90% 的时间都在用它。         |
| **挤出**      | **Extrude**                 | (Quad Draw模式下) 按住 **Tab** + 拖拽边  | **快速延伸几何体**。用于快速拉出新的面带（Face Loop），特别适合构建眼眶、嘴唇周围的环形结构。       |
| **松弛/平滑**   | **Relax / Smooth**          | (Quad Draw模式下) 按住 **Shift** + 涂抹 | **均匀布线**。自动计算并平均化顶点的间距，使网格分布更整洁。类似于“熨平”布线。                  |
| **软选择**     | **Soft Selection**          | 按 **B** 键 (或在工具设置中勾选)            | **调整大形**。在移动顶点时，让周围的顶点产生衰减跟随移动。用于调整大块区域的形状，避免逐个点调整导致表面凹凸不平。 |
| **编辑边流向**   | **Edit Edge Flow**          | `Edit Mesh > Edit Edge Flow`     | **圆滑结构**。自动根据曲率调整选中的循环边，使其更加圆润自然。常用于修正手动布线时产生的生硬转折。         |
| **镜像**      | **Mirror**                  | `Shift + 右键` > Mirror            | **对称复制**。将做好的半边脸拓扑复制到另一边并合并。做完一半后必须执行的操作。                   |
| **隔离选择**    | **Isolate Select**          | `Ctrl + 1` / 面板上方图标              | **独显模式**。隐藏其他干扰物体，只显示当前操作的模型。用于检查中心点是否对齐或内部结构。              |
| **中心归零**    | **Center Pivot / Set to 0** | 输入框 (Channel Box)                | **中线对齐**。选中中心线上的所有顶点，在 X 轴坐标输入 `0`，确保镜像时能完美缝合。              |
| **Z重构网格**   | **ZRemesher**               | (ZBrush 软件功能)                    | **自动拓扑**。视频中提到用于静态物体（如褶皱布料），但不建议用于需要精确动画控制的面部。              |

## 2. 核心术语概念 (Key Concepts)

理解这些术语对于听懂教程和查阅文档至关重要。

- **Retopology (拓扑重建)**: 在高面数模型（High Poly）表面重新构建低面数、布线合理模型（Low Poly）的过程。
    
- **Quads (四边面)**: 由四个顶点组成的面。**最理想的拓扑结构**，利于细分（Subdivide）和动画形变。
    
- **Triangles (三角面)**: 由三个顶点组成的面。在非形变区域（如耳朵内部、头皮）可以少量存在，但在口轮匝肌、眼轮匝肌等运动区域应避免。
    
- **N-gons (多边面)**: 超过四条边的面（如五边形）。**绝对禁止**，会导致渲染错误和软件兼容性问题。
    
- **Poles / Stars (极点/星形点)**: 5条或更多线汇聚的点。用于改变布线流向（Edge Flow），应藏在运动幅度较小的区域。
    
- **Edge Loop (循环边)**: 首尾相连的一圈边，对于面部表情动画至关重要（如围绕眼睛和嘴巴的圈）。
    
- **Landmarks (地标/关键点)**: 面部的重要特征区域，如眼角、嘴角、鼻翼。拓扑时应优先确立这些位置。
    

## 3. 拓扑重建全流程要点 (Workflow Summary)

视频演示了一个标准的生物头部拓扑流程，核心理念是 **“从大到小，先概括后细节”**。

### 第一阶段：准备工作 (Preparation)

1. **设置激活表面 (Make Live)**: 选中高模，点击磁铁图标，使其成为吸附对象。
    
2. **激活四边形绘制 (Quad Draw)**: 进入拓扑模式。
    

### 第二阶段：构建大形 (Blocking / Big Shapes)

- **核心原则**: **不要一开始就纠结细节！**
    
- **操作**:
    
    - 先在关键区域（眼眶、嘴唇、鼻梁）绘制大的多边形点。
        
    - 使用 **Tab + 拖拽** 快速挤出大的面片。
        
    - **忽略细节**: 即使眉毛处有明显的转折，初期也只用一个大的面带覆盖，细节留到后面加线。
        
    - **分块进行**: 专注于一个区域（如眼罩区域），做完后再移动到下一个区域（如嘴巴面罩）。
        

### 第三阶段：连接与填补 (Connecting)

- **拼图游戏**: 将之前分块做好的大面片（眼、口、鼻）连接起来。
    
- **使用软选择 (Soft Selection)**: 在连接过程中，如果发现整体形状不贴合，开启软选择移动大块顶点，保持整体平滑。
    
- **处理极点 (Poles)**: 在连接不同流向的区域时（如脸颊侧面），自然会形成五星点（Pole），这是改变布线方向的必要结构，无需恐慌。
    

### 第四阶段：细化与平滑 (Refining)

- **增加循环边**: 只有在大形确定后，才按住 `Ctrl` (Quad Draw内) 插入循环边来增加细节。
    
- **Shift 平滑**: 频繁使用 `Shift + 拖拽` 来均匀化布线，使网格整洁。
    
- **检查密度**: 眼睛和嘴巴周围需要较高的密度（为了表情动画），而头顶和后脑勺可以保持较低密度。
    

### 第五阶段：对称与内部结构 (Symmetry & Inner Structures)

1. **中线对齐**: 选中中间线的所有顶点，X轴坐标归零。
    
2. **镜像 (Mirror)**: 复制并合并对称的另一半。
    
3. **内部建模**:
    
    - **眼袋/眼皮厚度**: 暂时关闭 Quad Draw 或结合常规建模工具，向内挤出制作厚度。
        
    - **口腔袋 (Mouth Bag)**: 向内挤出嘴唇边缘，构建口腔内部空间（有助于次表面散射 SSS 渲染效果）。
        
4. **最终修整**: 使用 `Edit Edge Flow` 修正生硬的挤出边缘。
    

## 4. 专家建议 (Pro Tips)

1. **关于三角面 (Triangles)**: 不要对三角面有“洁癖”。如果为了消除一个三角面而不得不增加几百个无用的四边面，那么**保留三角面是更好的选择**。只要不放在关节弯曲或表情丰富的地方即可。
    
2. **关于自动拓扑**: 对于静态物体（如衣服褶皱），可以使用 ZBrush 的 ZRemesher 偷懒；但对于**人脸/生物头部**，必须手动拓扑以保证布线流向支持动画。
    
3. **零件复用**: 对于耳朵、手脚等结构复杂且通用的部位，建议做一个完美的低模保存起来。下次做新角色时，直接把现成的耳朵“缝”上去，不仅省时而且质量高。
    
4. **大卫·爱登堡解说模式**: 拓扑过程枯燥时，请放轻松的播客或音乐，把它当成一种“禅意”的解谜游戏。
