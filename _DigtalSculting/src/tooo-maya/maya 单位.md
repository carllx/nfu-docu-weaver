
In Maya, when I set the unit of the entire window to meters in the preferences, my mouse wheel becomes very difficult to control. Even a slight movement causes it to fly far away.

Adjust Camera Tool Settings 

You can adjust the camera's Dolly (zoom) speed directly in the tool settings for more granular control. 

- Go to **View > Camera Tools > Zoom Tool** (or Dolly Tool) **> Tool Settings** (the small square next to the tool name).
- In the Tool Settings window, locate the **Dolly Scale** slider and reduce its value (the default is 1.0; a smaller number like 0.1 or 0.01 will significantly decrease sensitivity).
