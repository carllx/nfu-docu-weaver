# Epistemic Rules：知识与证据规则

## 1. 内容身份

所有重要陈述必须尽可能标记为：

- `source-claim`：来源明确表达
- `secondary-interpretation`：二手材料的解释
- `agent-inference`：Agent 根据材料作出的推论
- `user-judgment`：用户明确作出的判断
- `project-decision`：已接受的项目决定
- `uncertain`：证据不足
- `question`：尚未解决的问题

## 2. 禁止越界

Agent 不得：

- 把推论写成作者原意；
- 把 Sources 称为“真理”（Sources 是不可随意改写的证据材料，可能存在错误或冲突；Wiki 才是当前可修订的综合理解）；
- 把艺术作品效果写成艺术家明确意图；
- 把用户尚未填写的模板当作用户决定；
- 仅凭标题判断笔记角色；
- 仅凭模型记忆补充 Vault 中不存在的出处；
- 将“视角不同”轻率标记为“直接矛盾”；
- 用高置信度掩盖跨学科外推。

## 3. 关系标签

允许使用：

- `supports`
- `extends`
- `contrasts`
- `contradicts`
- `uncertain`

其中 `contradicts` 只有在两个来源对相同问题作出不相容判断时才能使用。

如果只是理论层级、研究对象或语境不同，应使用 `contrasts` 或 `uncertain`。

## 4. 引用要求

至少记录：

- 文件路径
- 作者或资料来源
- 章节或标题
- 可定位的段落锚点
- 有页码时记录页码
- 无页码时明确标记“转换文本未保留页码”

Wiki 以概括为主体，短引文作为证据。

## 5. 决定权限

Agent可以：

- 搜索
- 分类候选
- 提出解释
- 提出课程建议
- 提出新建、合并或拆分方案
- 标记不确定性

只有用户可以确认：

- 课程价值取向
- 最终教学安排
- 正式 Wiki 的结构调整
- 对旧笔记的批量修改
- 项目优先级
