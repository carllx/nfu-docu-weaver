# 术语表 (Glossary)

以下是本项目中特殊术语的统一定义。

## 1. 核心架构层词汇
- **Source**: 证据材料。原始输入（如 PDF、书籍转换文本、访谈等），默认只读，是不可随意改写的证据，但不等于绝对真理。
- **Wiki**: 共享知识。由多个来源持续更新的编译层，跨项目复用，以概括为主体，包含已被综合的理解。
- **Project**: 真实项目层。保存具体目标、进度、任务和产出的文件夹（如《造物与创格》课程）。项目页面引用 Wiki，但不应冒充通用知识。
- **Personal Thinking**: 用户判断。保存用户的研究判断、教学取舍、未验证假设和对 Agent 建议的决定。不得被 Agent 自动覆盖。

## 2. 认识论与归属词汇
- **Agent Inference**: Agent 推论。Agent 根据材料得出的解释或关联。必须清楚标注，严禁将其表述为作者的原意或用户的决定。
- **Decision**: 决定。特指项目中已确认的方向、边界或设计选择，需记录在 Decision Log 中。

## 3. 工作流程与技术词汇
- **Pilot**: 试验/原型验证。在全面自动化或大面积重构前，使用小规模真实样本进行的能力验证测试（如跨来源三页隔离原型）。
- **RAG (Retrieval-Augmented Generation)**: 检索增强生成。目前阶段暂不建立全库 RAG，而是依赖明确的路径、目录、全文搜索和双链。
- **Skill**: 处理特定输入或任务的可重复流程，包含一系列 Agent 执行规则和最佳实践。注意：书籍等资源本身不是 Skill。
- **Compilation**: 编译/综合。Agent 提取不同来源的证据并融合为结构化、高密度 Wiki 页面的动作。
- **Lint**: 检查/审计。检查 Wiki 系统中的重复、孤岛、冲突、缺失引用、过度推论等问题，维护知识健康度。

## 4. 知识内容标签
- `source-claim`: 来源明确表达
- `secondary-interpretation`: 二手解释
- `agent-inference`: Agent 推论
- `user-judgment`: 用户判断
- `project-decision`: 已确认项目决定
- `uncertain`: 证据不足
- `question`: 开放问题
