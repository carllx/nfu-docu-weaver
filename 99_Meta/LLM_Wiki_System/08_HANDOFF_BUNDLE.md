# Portable Handoff Bundle

这是提供给新 ChatGPT 对话或新 Agent 的精简交接文件。

## 项目是什么

我们正在现有复杂 Obsidian Vault 上建立基于 LLM Wiki 思想的知识系统。

当前第一个真实项目是：

《造物与创格》八周实践课程。

## 核心原则

- Sources 只读。
- Wiki 是跨来源、可持续修订的共享知识。
- Project 保存具体课程和产出。
- 用户判断不得与 Agent 推论混写。
- 聊天不是正式项目记忆。
- 重要决定必须写入 Decision Log。
- 先小规模测试，后扩大自动化。
- 暂时不建立全库 RAG。

## 当前进度

已经完成：

- Vault 调查
- 检索能力测试
- 单来源 Pilot
- 跨来源 Pilot
- 三页隔离测试

当前发现：

- Agent 能搜索和初步综合；
- Agent 容易将推论写得过强；
- 需要严格的证据规则；
- 尚未测试长期更新已有 Wiki。

## 当前任务

建立项目记忆系统，并继续确定《造物与创格》的课程边界。
